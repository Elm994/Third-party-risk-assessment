# Data Classification and Data Flows

## Data Classification Levels

| Classification | Description |
|---|---|
| Public | Information approved for public release |
| Internal | Non-public operational information |
| Confidential | Sensitive business or customer data |
| Restricted | Highly sensitive regulated information |

## Data Flow Requirements

Document:

- Data collection points
- Data processing activities
- Storage locations
- International transfers
- Backup locations
- AI processing activities
- Sub-processor involvement

  ## Required Evidence

- Architecture diagrams
- Data flow diagrams
- Data retention policies
- Encryption standards
- Data residency declarations
